# Corridor Finder

**Which Stellar anchors and payment rails actually connect country A to country B?**

Corridor Finder is an open-source tool that shows real Stellar on/off-ramps, assets and routes for a country pair, with the source and age of every fact. It never invents fees, speed, liquidity or availability: unknown means *unavailable*.

| Repository | Purpose |
| --- | --- |
| [corridor-finder](https://github.com/corridor-finder/corridor-finder) | Product definition, architecture, decisions, roadmap |
| [corridor-finder-registry](https://github.com/corridor-finder/corridor-finder-registry) | Sourced anchor and corridor data, schema, validator |
| [corridor-finder-api](https://github.com/corridor-finder/corridor-finder-api) | Anchor verifiers and REST API (NestJS) |
| [corridor-finder-web](https://github.com/corridor-finder/corridor-finder-web) | Web application (Next.js) |
